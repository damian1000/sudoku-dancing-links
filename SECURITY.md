# Security Policy

## Reporting a Vulnerability

If you find a security issue in this project, please report it privately rather than opening a public issue:

- Email: damian.howard@gmail.com
- Or use GitHub's private vulnerability reporting via the **Security** tab.

You can expect an initial acknowledgement within 14 days.

## Supported Versions

This project follows main-branch development; security fixes are applied to the latest commit on the default branch.
